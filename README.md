# Mopuru Pavanesh — Portfolio

A single-file portfolio for sharing with recruiters. It covers Way2News, the production numbers, technical skills, the Split Expense project, education, and contact details.

The page opens with a short loader, then a particle field, a moving skill ticker, count-up stats, and scroll-drawn experience. If the visitor has reduced motion turned on, those animations stay still.

## Use it

`index.html` is the whole site. There is no build step and nothing to install.

- Open `index.html` in a browser, or
- Upload that one file to any static host: GitHub Pages, Netlify, Cloudflare Pages, Amazon S3, or your own server.

Contact links go to email, phone, and LinkedIn. The page prints cleanly if you need a PDF from the browser.

## Edit

All copy and styles live in `index.html`. Change the text there, save, and upload the file again.
